这套设计如何避免“旧记忆复活”

记忆服务故障时，普通聊天可以降级，但不会伪装成“已经保存”。显式记住/遗忘操作返回真实回执。

01

SQLite 权威库

缓存和向量索引都可重建；注入前用同一快照复核。

02

Erase barrier

删除后推进代际，旧摘要、旧事实和旧索引候选不再可提交。

03

持久任务

摘要、事实抽取和索引清理可重试，重启不会丢掉状态。
